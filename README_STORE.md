# 📊 Análisis de Ventas – Google Colab

Este proyecto tiene como objetivo realizar un análisis exploratorio de datos de ventas mediante **Python** en **Google Colab**, con el fin de obtener métricas relevantes y visualizar patrones comerciales a partir de un conjunto de datos simulado.

## 🔍 Contenido del análisis

1. **Facturación total**  
   Cálculo del monto total de ventas, con desglose por cliente y producto.

2. **Ventas por categoría**  
   Identificación y visualización de las categorías con mayor volumen de ventas.

3. **Calificación promedio de la tienda**  
   Estimación del nivel de satisfacción de los clientes (datos simulados).

4. **Productos más y menos vendidos**  
   Determinación de los artículos con mayor rotación y de aquellos con menor demanda.

5. **Costo de envío promedio por tienda**  
   Comparación de los costos logísticos entre distintas tiendas (valores simulados).

## 🛠️ Herramientas utilizadas

- **Python**: pandas, matplotlib, numpy  
- **Google Colab**  
- **Markdown** para documentación
